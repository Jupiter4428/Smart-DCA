│                          #    - MONTHLY_DCA_BUDGET_USD: งบ DCA ต่อเดือน (USD)
│                          #    - ANNUAL_GROWTH_TARGET: เป้าหมายเติบโต 12% ต่อปี

│                          #    - REBALANCE_TOLERANCE, DEFAULT_EXCHANGE_RATE, EXCHANGE_RATE_TIMEOUT

    │                      #    - calculate_rsi(close, period=14): Wilder's Smoothing RSI

    │                      #    - print_portfolio_status(...): แสดงตาราง rebalance ใน console
    │                      #    - get_action_signal(current_pct, target_pct, rsi): คืน BUY/SELL/SKIP/HOLD/DCA + เหตุผล
    ├── utils.py           # 🔧 Utility Functions
    │                      #    - get_thb_usd_rate(): ดึง rate จาก yfinance → exchangerate-api → default fallback

    │                      #    - format_currency(value, symbol): จัดรูปแบบตัวเลขสกุลเงิน
    │                      #    - format_percentage(value): จัดรูปแบบเปอร์เซ็นต์

    │                      #    - generate_dca_action_report(rate): ตาราง DCA recommendation + action signal
    │                      #    - generate_technical_report(): ตาราง RSI, MACD, Signal ทุกหุ้น
    │                      #    - print_reports_to_console(rate): แสดงรายงานทั้งหมดใน terminal

    │                      #    - append_performance_history(rate): บันทึก snapshot รายวัน → portfolio_history.csv
